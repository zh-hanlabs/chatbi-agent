# EXP-001:RAG 检索参数对比实验(chunk × TopK × 相似度阈值)

- 任务:T-011(REQ-001)
- 日期:2026-10-24
- 运行方式:`GET /api/experiments/rag-sweep`(离线复算,不依赖库表);复现:`mvnw test -Dtest=RagSweepExperimentTests`

## 实验设置

- **语料**:两篇业务口径/区域说明短文档 + 一篇 ~1.6k 字运营手册(保证 chunk 尺寸轴有区分度)
- **用例**:评估集 RAG 15 条、拒答 10 条(与线上评估同源)
- **指标**:
  - RAG 命中率 = recall@K,期望内容落在 TopK 任一命中块即算命中
  - 拒答准确率 = Top1 相似度低于阈值而正确拒答的比例
- **扫参**:chunk ∈ {300, 500, 800}(overlap 50)× TopK ∈ {1, 3} × minScore ∈ {0.1, 0.2, 0.3},共 18 组

## 结果

| chunk | topK | minScore=0.1 命中/拒答 | minScore=0.2 命中/拒答 | minScore=0.3 命中/拒答 |
| --- | --- | --- | --- | --- |
| 300 | 1 | 0.93 / 0.10 | 0.93 / 0.70 | 0.67 / 1.00 |
| 300 | 3 | 0.93 / 0.10 | 0.93 / 0.70 | 0.67 / 1.00 |
| 500 | 1 | 0.93 / 0.10 | 0.93 / 0.70 | 0.67 / 1.00 |
| **500** | **3** | **1.00** / 0.10 | **0.93 / 0.70(线上配置)** | 0.67 / 1.00 |
| 800 | 1 | 0.93 / 0.10 | 0.93 / 0.70 | 0.67 / 1.00 |
| 800 | 3 | 1.00 / 0.10 | 0.93 / 0.70 | 0.67 / 1.00 |

## 结论

1. **阈值是主导变量**:0.1→0.2→0.3 时,拒答准确率 0.10→0.70→1.00,RAG 命中率 0.93~1.00→0.93→0.67。召回与拒答是一对此消彼长的指标,不存在两头全占的配置。
2. **TopK=3 优于 1**:低阈值下 chunk=500/800 + TopK=3 达到 100% 召回(TopK=1 只有 93%),说明期望块偶尔不在第一位,放宽窗口可以捞回。
3. **chunk 尺寸在 300~800 间几乎不影响结果**:哈希 bigram 向量按词频重叠打分,块大小只要覆盖住一个完整口径句,命中率不变;尺寸轴的真实影响要等接入真实 Embedding API 后重跑验证。
4. **线上配置(chunk=500, TopK=3, minScore=0.2)是合理工作点**:RAG 命中 93%、拒答 70%。若产品定位更怕「答非所问」可上调至 0.25 左右;更怕「漏答」可下调至 0.15 并接受少量误答。
5. 单调性校验已固化为测试:同配置下 TopK=3 召回 ≥ TopK=1;阈值 0.3 拒答 ≥ 0.1。
